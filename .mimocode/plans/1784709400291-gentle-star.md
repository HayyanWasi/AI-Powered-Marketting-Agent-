# Plan: LLM-Powered Prompt Refinement & Copy Generation

## Problem
When user enters a prompt like "i want to generate campaigns for AI seminar for Agentic AI":
1. **Image**: Raw prompt is passed directly to Cloudflare FLUX → produces garbled text, nonsensical images
2. **Copy**: Hardcoded template `"Discover X. Transform your approach..."` repeated every time → irrelevant, generic content

## Solution
Add two LLM calls in `_execute_campaign_generation()` using the existing `LLMService` (OpenAI gpt-4o / Gemini fallback):
1. **Refine image prompt** — rewrite user's raw prompt into a descriptive visual scene for image models
2. **Generate marketing copy** — create real headlines, body, CTA, hashtags based on prompt + brand context

## File to Modify
`backend/src/api/routes/workflow.py` — only the `_execute_campaign_generation()` function

## Changes

### Step 1: Add LLM-based image prompt refinement (before Cloudflare call)

After getting `brand_context` and before image generation, add:

```python
from src.services.llm_service import LLMService
from src.models.llm import LLMRequest

llm = LLMRequest(
    system_prompt="""You are an expert image prompt engineer for AI image generation models like FLUX and Stable Diffusion.

Given a user's campaign idea and brand context, write a single, concise image generation prompt (under 200 words) that:
- Describes a specific, visually compelling scene (not text overlays)
- Includes brand colors, mood, and style
- Avoids generating text/words in the image (AI models are bad at text)
- Is formatted as a visual description, not a marketing brief
- Focuses on atmosphere, composition, and visual elements

Return ONLY the refined prompt, nothing else.""",
    user_prompt=f"Campaign idea: {prompt}\n\nBrand colors: {brand_context.color_palette or 'not specified'}\nBrand personality: {brand_context.personality_descriptors or 'professional'}\nStyle guidance: {brand_context.style_guidance or 'modern, clean'}"
)

try:
    llm_service = LLMService()
    response = llm_service.generate(llm)
    refined_prompt = response.text.strip()
except Exception as e:
    logger.warning("LLM prompt refinement failed, using fallback: %s", e)
    refined_prompt = f"Professional marketing campaign: {prompt}, modern clean design"
```

Then pass `refined_prompt` instead of the raw prompt to Cloudflare/Pollinations.

### Step 2: Add LLM-based copy generation (replace hardcoded templates)

Replace the hardcoded copy block with:

```python
copy_llm = LLMRequest(
    system_prompt="""You are an expert marketing copywriter. Generate social media campaign copy.

Return a JSON object with exactly these fields:
{
  "headlines": ["headline1", "headline2", "headline3"],
  "body_copy": "Main body text for the post (2-3 sentences, engaging and concise)",
  "cta": "Call to action text",
  "hashtags": ["#tag1", "#tag2", "#tag3", "#tag4", "#tag5"]
}

Rules:
- Headlines should be catchy, short (under 10 words each)
- Body copy should be professional but engaging
- Hashtags should be relevant to the campaign topic
- Match the brand tone provided
- Return ONLY valid JSON, no markdown fences""",
    user_prompt=f"Campaign: {prompt}\n\nBrand tone: {brand_context.personality_descriptors or 'professional'}\nTarget platforms: instagram, linkedin, facebook"
)

try:
    response = llm_service.generate(copy_llm)
    import json
    copy_data = json.loads(response.text.strip().removeprefix("```json").removesuffix("```").strip())
except Exception as e:
    logger.warning("LLM copy generation failed, using fallback: %s", e)
    copy_data = {
        "headlines": [f"Introducing {prompt}", "Your solution awaits", "Transform today"],
        "body_copy": f"Discover {prompt}. Transform your approach with our innovative solution.",
        "cta": "Learn More",
        "hashtags": ["#Marketing", "#Campaign", "#Innovation"],
    }
```

Then use `copy_data` to build the asset:
```python
copy_asset = CampaignAsset(
    campaign_id=campaign.id,
    asset_type=AssetType.COPY,
    content={
        "text": copy_data["body_copy"],
        "headlines": copy_data["headlines"],
        "cta": copy_data["cta"],
        "hashtags": copy_data["hashtags"],
    },
    source=AssetSource.AI,
    created_by=actor_id,
)
```

### Step 3: Consolidate — remove duplicate prompt construction

Remove the manual string concatenation for `rich_prompt` and use the `refined_prompt` from Step 1 instead. Remove the old `PollinationsPrompt` import if no longer needed (Cloudflare path doesn't use it).
